# Padel Social Club — Mini Landing

Мини-лендинг падел-клуба на Next.js (App Router) с CSS-модулями.

## Референс

Скриншот: `docs/padel.png` (Pinterest — Padel Social Club)

## Стек

- Next.js 15 (App Router)
- TypeScript
- CSS Modules
- Google Fonts: Inter, Space Grotesk

## Секции

- Header — навигация поверх Hero
- Hero — Motion. Discipline. Result. + карточка рейтинга 4.8 + CTA
- Marquee — бегущая строка PADEL SOCIAL CLUB
- Energy — Experience the true energy of padel
- Trainers — карточки Max Davis / Alex Mercer
- CourtSection — Elevate Your Padel Game
- Footer — CTA + логотип + копирайт

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000)

## Скрипты

- `npm run dev` — запуск dev-сервера
- `npm run build` — production-сборка
- `npm run start` — запуск production-сборки
- `npm run lint` — проверка ESLint
